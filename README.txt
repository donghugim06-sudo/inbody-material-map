InBody 자재 위치 관리 웹사이트

실행 방법
1. ZIP 파일 압축을 풉니다.
2. VS Code에서 폴더를 엽니다.
3. Live Server로 index.html을 실행합니다.
4. 인터넷 연결이 필요합니다. Firebase Firestore와 실시간으로 동기화됩니다.

주요 기능
- InBody Red #971B2F 디자인
- 12가지 색상 네모 선택 팔레트
- 세로 칸 추가 / 가로 칸 추가
- 세로 칸 삭제 / 가로 칸 삭제
- 선택한 칸의 자재 정보 비우기
- 배치도에서 칸을 먼저 선택한 뒤 자재명과 품번 등록 및 수정
- 검색 및 검색 결과 강조
- 드래그 앤 드롭으로 자재 이동 및 교환 (빈 칸 이동 시 원래 칸 비움)
- 로컬 변경 저장 중 오래된 Firebase 스냅샷이 화면을 덮어쓰지 않도록 보호
- 자재 수정 시 원래 위치와 목적지 자재를 올바르게 교환
- PC와 모바일 화면 대응
- Firebase Firestore 실시간 공유

칸 삭제 안내
세로 칸 삭제와 가로 칸 삭제는 가장 마지막 열 또는 행을 제거합니다. 해당 행/열에 자재가 있으면 확인 창이 표시되며, 진행하면 그 자재 데이터도 삭제됩니다. 특정 칸만 비우려면 배치도에서 해당 칸을 선택하고 '선택 칸 비우기'를 누르세요.

주의
기존 Firebase 프로젝트 설정을 사용합니다. Firestore 규칙이 누구나 읽기/쓰기를 허용하도록 설정되어 있다면 테스트용으로만 사용하세요. 실제 회사의 민감한 자재 정보는 입력하지 마세요.
